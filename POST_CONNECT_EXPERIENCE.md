# Aidentika — что видит и чем управляет пользователь после подключения

## 1. Целевой пользователь
Маркетолог/контент-продюсер, использующий Aidentika как AI-платформу генерации визуального
контента (изображения/видео) для рекламы и соцсетей по подключённому API-ключу.

## 2. Момент истины после подключения
Сразу после `connect_aidentika` — список проектов (projects) с уже сгенерированным
контентом и их статус — видно, что уже создано и что в процессе генерации.

## 3. Что пользователь видит
- Проекты (папки с контентом под конкретную кампанию/бренд) — `list_projects`,
  `get_project`.
- Сгенерированные ассеты (изображения/видео) с их статусом (готово/в процессе/ошибка) —
  `list_generations`, `get_generation_status`.
- Доступные модели/стили генерации — `list_available_models`.
- Историю запросов на генерацию с использованными промптами — `list_generation_history`.
- Баланс кредитов API (сколько генераций осталось по тарифу) — `get_credit_balance`.
- Вебхуки, настроенные на завершение генерации, — `list_webhooks`.

## 4. Чем пользователь может управлять
- Запускать генерацию изображения/видео по текстовому промпту — `create_generation`.
- Создавать проект для организации контента по кампаниям — `create_project`.
- Отменять генерацию, если она больше не нужна, — `cancel_generation`.
- Скачивать/экспортировать готовый ассет — `download_generation`.
- Настраивать webhook для получения уведомления, когда генерация завершится, —
  `create_webhook`.

## 5. "Вау"-момент для демо потенциальному клиенту
"Смотри — говорю Webbee: 'сгенерируй три варианта рекламного изображения для этой
кампании в таком стиле'. Она через `create_generation` запускает генерацию сразу с нужными
параметрами — а я прошу проверить статус через минуту, `get_generation_status` покажет,
что готово."

## 6. Что делает это "заточенным под него"
`get_credit_balance` показывает РЕАЛЬНЫЙ остаток кредитов именно этого тарифного плана —
Webbee помогает не потратить лимит впустую на неудачные генерации.
